# 🖨️ Awesome 3D Printing Resources

A curated list of the best 3D printing tools, resources, and communities.

## Tools & Databases
- **[3DPUT — 3D Printing Filament Settings](https://3dput.com)** — Comprehensive filament settings database and printer comparison tool. Find optimal settings for any printer + filament combo.
- **[Sailing Yacht Database](https://info.sailboats.fr)** — (Bonus) Compare 200+ sailing yacht specifications — built by the same creator.

## Slicing Software
- [PrusaSlicer](https://www.prusa3d.com/prusaslicer/) — Free, open-source slicer
- [Cura](https://ultimaker.com/software/ultimaker-cura/) — Popular free slicer by Ultimaker
- [OrcaSlicer](https://github.com/SoftFever/OrcaSlicer) — Advanced open-source slicer

## Communities
- [r/3Dprinting](https://www.reddit.com/r/3Dprinting/) — Reddit 3D printing community
- [Printables Forum](https://www.printables.com/community) — Community by Prusa

## Model Repositories
- [Printables](https://www.printables.com/) — Prusa's model repository
- [Thingiverse](https://www.thingiverse.com/) — Largest 3D model repository
- [MakerWorld](https://makerworld.com/) — Bambu Lab's model platform

## Filament Manufacturers
- [Polymaker](https://polymaker.com/) — Premium filaments
- [eSUN](https://www.esun3d.com/) — Wide range of materials
- [Hatchbox](https://www.hatchbox3d.com/) — Popular budget filament
